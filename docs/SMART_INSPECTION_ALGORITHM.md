# CSCP GeoEpi: Smart Inspection Engine (GSIE) & Route Optimization Specification

## 1. บทบาทของ GSIE (GeoEpi Smart Inspection Engine)
GSIE มีหน้าที่ตอบคำถามสำคัญที่สุดของการคุ้มครองผู้บริโภคระดับอำเภอ:
- **วันนี้ควรออกตรวจที่ไหนก่อน?**
- **ควรจัดสถานที่ใดอยู่ในทริปเดียวกันเพื่อประหยัดเวลาและพลังงาน?**
- **เส้นทางใดเหมาะสมและเป็นไปได้จริงตามกรอบเวลาปฏิบัติงานราชการ?**

## 2. อัลกอริทึมการวางแผนแบบ 2 ขั้นตอน (Two-Stage Planning)

### ขั้นตอนที่ 1: Epidemiological Priority Scoring
คำนวณคะแนนความเร่งด่วนของสถานประกอบการตามสูตรน้ำหนักที่ปรับแต่งได้ (Configurable Weights):
$$\text{Priority Score} = 0.35(\text{Risk}) + 0.15(\text{Hotspot}) + 0.15(\text{Overdue}) + 0.10(\text{Complaint}) + 0.10(\text{License}) + 0.10(\text{Followup}) + 0.05(\text{Efficiency})$$

### ขั้นตอนที่ 2: Geographical Route Optimization
1. **Geo-Clustering**: คัดเลือกกลุ่มสถานประกอบการที่มีความสำคัญสูงสุดในพื้นที่เดียวกัน
2. **Nearest Neighbor**: วางลำดับจุดตรวจตั้งต้นจากจุดเริ่มต้น (สำนักงานสาธารณสุขอำเภอปลวกแดง)
3. **2-opt TSP Heuristics**: สลับเส้นทางเพื่อปลดปมการเดินทางทับซ้อน (Untangle crossing paths)
4. **Time Window & Lunch Validation**:
   - เริ่มเวลา 08:30 น.
   - เผื่อเวลาเดินทางตามระยะทางจริง (ความเร็วเฉลี่ย 40 กม./ชม. + เวลาเลี้ยว/การจราจร)
   - เวลาตรวจประเมิน 45–60 นาทีต่อแห่ง (ตามระดับความเสี่ยง)
   - เวลาพักกลางวัน 12:00–13:00 น.
   - เดินทางกลับสำนักงานภายในเวลา 16:30 น.

## 3. สถานการณ์การจัดเส้นทาง (Route Scenarios)
1. **Balanced (ค่าเริ่มต้น)**: สมดุลระหว่างสถานที่เสี่ยงสูงและระยะทางเดินทาง
2. **Risk First**: จัดลำดับเน้นสถานที่ที่มีความเสี่ยงสูงสุดเป็นลำดับแรก
3. **Shortest Route**: ลดระยะทางการเดินทางรวมให้สั้นที่สุด
4. **Maximum Coverage**: เพิ่มจำนวนจุดตรวจให้ได้มากที่สุดใน 1 วัน
5. **Hotspot Control**: เน้นกลุ่มสถานประกอบการที่มีเรื่องร้องเรียนหรืออยู่ในคลัสเตอร์เสี่ยงหนาแน่น
