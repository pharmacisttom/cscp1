# CSCP GeoEpi: GIS Architecture & Map Engine Specification

## 1. ข้อมูลภาพรวม
CSCP GeoEpi ได้รับการออกแบบสถาปัตยกรรม GIS ให้เป็น **Map-First Architecture** ซึ่งใช้แผนที่อัจฉริยะ (Smart Map) เป็น Control Center หลักสำหรับผู้บริหารและพนักงานเจ้าหน้าที่สาธารณสุข

---

## 2. โครงสร้างโมดูล GIS (`src/lib/maps/`)
```
src/lib/maps/
├── coordinates.ts     # การแปลงพิกัด WGS84, DMS, การตรวจสอบขอบเขตประเทศไทย/ระยอง
├── distance.ts        # การคำนวณระยะทาง Haversine, Centroid, และประมาณการเวลาเดินทาง
├── layers.ts          # การกำหนดคุณลักษณะและสัญลักษณ์ของทั้ง 12 ชั้นข้อมูล
└── map-provider.ts    # Map Provider Interface (OpenStreetMap / CartoDB / Satellite)
```

---

## 3. สถาปัตยกรรมชั้นข้อมูลทั้ง 12 ชั้น (12 Map Layers)
| ลำดับ | ชั้นข้อมูล (Layer) | วัตถุประสงค์และการแสดงผล |
| :---: | :--- | :--- |
| 1 | **สถานประกอบการทั้งหมด** | หมุดแสดงตำแหน่งสถานประกอบการด้านสุขภาพทั้ง 305 แห่ง |
| 2 | **ระดับความเสี่ยง (Risk Level)** | หมุดจำแนกสีตามความเสี่ยง: เขียว (Low), เหลือง (Moderate), ส้ม (High), แดง (Critical) พร้อมสัญลักษณ์ตัวอักษรสำหรับผู้มีข้อจำกัดด้านการมองเห็นสี |
| 3 | **สถานะการตรวจประเมิน** | ตรวจแล้ว (Passed), มีเงื่อนไข (Conditional), รอตรวจ (Pending), เกินกำหนด (Overdue) |
| 4 | **ใบอนุญาตหมดอายุ** | กรองสถานประกอบการที่ใบอนุญาตหมดอายุหรือใกล้หมดอายุภายใน 90 วัน |
| 5 | **เรื่องร้องเรียน (Complaint)** | แสดงหมุดสีม่วงพร้อมเครื่องหมายตกใจ (!) สำหรับสถานประกอบการที่มีเรื่องร้องเรียนค้างอยู่ |
| 6 | **เกินกำหนดตรวจ (Overdue)** | แสดงหมุดสีส้มเข้มสำหรับสถานประกอบการที่รอบการตรวจเกิน 365 วัน |
| 7 | **ต้องติดตามผล (Follow-up)** | สถานประกอบการที่ตรวจไม่ผ่านและต้องลงตรวจซ้ำ |
| 8 | **จุดเสี่ยงหนาแน่น (Hotspot)** | วงรัศมีคลัสเตอร์สีแดงความโปร่งใส คำนวณด้วยอัลกอริทึม DBSCAN |
| 9 | **ความครอบคลุมการตรวจ** | ชั้นข้อมูลความหนาแน่นและร้อยละการตรวจรายตำบล |
| 10 | **คุณภาพข้อมูล (Data Quality)** | หมุดสีเทาสำหรับสถานประกอบการที่ยังไม่มีพิกัด GPS หรือพิกัดไม่สมบูรณ์ |
| 11 | **ขอบเขตตำบล** | เส้นแบ่งเขตการปกครอง 7 ตำบลในอำเภอปลวกแดง |
| 12 | **เส้นทางออกตรวจ (Daily Route)** | เส้นทาง Polyline เชื่อมโยงลำดับจุดตรวจประจำวันตามการคำนวณของ GSIE |

## 4. Bounding-Box Caching & Viewport Optimization
เพื่อรองรับข้อมูลสถานประกอบการจำนวนมาก:
- API `/api/map/businesses` รับพารามิเตอร์ `minLat`, `maxLat`, `minLng`, `maxLng`
- โหลดเฉพาะข้อมูลหมุดที่อยู่ใน Viewport ของแผนที่
- ส่งเฉพาะฟิลด์ขนาดเล็ก (`id, name, lat, lng, type, risk, status`)
- เมื่อผู้ใช้คลิกหมุด จึงจะ Fetch รายละเอียดฉบับเต็มผ่าน `/api/map/business/[id]` แบบ Lazy-loaded
