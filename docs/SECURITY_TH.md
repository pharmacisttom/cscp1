# CSCP GeoEpi: ความมั่นคงปลอดภัยสารสนเทศ (Security Architecture & RBAC)

## 1. บทบาทและสิทธิการใช้งาน (Role-Based Access Control - RBAC)
1. **SUPER_ADMIN**: ผู้ดูแลระบบโครงสร้างพื้นฐานระดับเซิร์ฟเวอร์
2. **ADMIN**: ผู้ดูแลระบบระดับอำเภอ / จังหวัด
3. **DISTRICT_MANAGER**: ผู้บริหารและหัวหน้ากลุ่มงาน (ดูสรุป, รายงาน, อนุมัติแผน)
4. **INSPECTOR**: พนักงานเจ้าหน้าที่หน้างาน (ตรวจประเมิน, ยืนยันพิกัด, บันทึกรูปภาพ)
5. **ANALYST**: นักวิชาการระบาดวิทยาและนักวิเคราะห์ข้อมูลเชิงพื้นที่
6. **VIEWER**: หน่วยงานร่วมสังเกตการณ์ (อ่านได้อย่างเดียว)

---

## 2. การเข้ารหัสและรักษาความปลอดภัยของรหัสผ่าน
- รหัสผ่านได้รับการแฮชด้วยอัลกอริทึม **Argon2** หรือ **Scrypt** พร้อม Salt สุ่มขนาด 16 ไบต์ ป้องกันการโจมตีแบบ Rainbow Table
- รองรับการยืนยันตัวตนแบบ 2 ขั้นตอน (TOTP 2FA) ตามมาตรฐาน RFC 6238 จากสถาปัตยกรรม Tomvis

---

## 3. บันทึกประวัติการเปลี่ยนแปลง (Audit Logging)
ทุกกิจกรรมสำคัญจะถูกบันทึกลงในตาราง `auditlog`:
- การเข้าสู่ระบบ (`LOGIN`)
- การสร้าง / ปรับปรุง / ลบข้อมูล (`CREATE`, `UPDATE`, `DELETE`)
- การนำเข้าข้อมูลไฟล์ Excel (`IMPORT`)
- การตรวจประเมิน (`INSPECTION`)
- การสร้างและปรับเปลี่ยนเส้นทางตรวจ (`PLAN_GENERATED`, `PLAN_OVERRIDDEN`)
- การยืนยันหรือแก้ไขพิกัด GPS หน้างาน (`COORDINATE_CHANGED`)

---

## 4. หลักการตัดสินใจร่วมกับมนุษย์ (Human Decision Support & Override)
อัลกอริทึม GSIE และ GeoEpi Risk เป็นเครื่องมือสนับสนุนการตัดสินใจ (Decision Support System) มิใช่ผู้ตัดสินแทนเจ้าหน้าที่:
- เจ้าหน้าที่สามารถ Override เส้นทาง, ลำดับจุดตรวจ หรือปรับเปลี่ยนคะแนนความเสี่ยงได้ตลอดเวลา
- ทุกการ Override จะต้องมีการระบุเหตุผลและบันทึกประวัติไว้ในระบบอย่างโปร่งใส
